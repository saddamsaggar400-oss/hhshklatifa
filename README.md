# hhshklatifa — واجهة محادثات عربية

تم تحويل المشروع إلى واجهة محادثات تشبه واتساب، مع الاحتفاظ بحساب **hhshklatifa** وصورته الأصلية واسمه «لطيفة بنت محمد بن راشد آل مكتوم» والعلامة الزرقاء الموجودة في التصميم المرفق. الحساب يظهر عند فتح الرابط قبل تسجيل الدخول، ويستطيع الزائر إنشاء حساب خاص به ثم مراسلته. اسم «وصال» اسم مبدئي لواجهة المحادثات ويمكن تغييره.

الصورة والاسم والشارة مأخوذة من مشروع المستخدم؛ الشارة عنصر محفوظ من التصميم ولا تمثل تحققًا من إنستغرام أو واتساب أو ربطًا بهما. لا يستطيع مستخدم جديد اختيار اسم `hhshklatifa` أو منح نفسه الشارة. ملفات الصفحة القديمة محفوظة في المصدر؛ مسارات الإدارة القديمة ليست التطبيق المشغّل.

## إعداد صاحب الحساب

لا تُشحن أي كلمة مرور ثابتة أو سرية للحساب الأساسي. يجهّز صاحب الخادم حسابه مرة واحدة من الطرفية:

```bash
pnpm install --frozen-lockfile
pnpm setup:account
pnpm dev
```

أدخل كلمة مرور جديدة مرتين؛ لن تظهر أثناء الكتابة. ثم افتح `http://localhost:5173`، واضغط «تسجيل الدخول»، وادخل باسم **hhshklatifa** وكلمة المرور التي اخترتها. ستظهر رسائل الزوار في قائمة محادثات صاحب الحساب ويمكنه الرد عليها. يمكن تنفيذ أمر الإعداد مجددًا لتغيير كلمة مرور هذا الحساب وإبطال جلساته القديمة. يستخدم الأمر نفس `CHAT_DB_PATH` الذي يستخدمه الخادم؛ اضبطه في كليهما عند تخصيص مسار البيانات.

يمكن تشغيل الواجهة قبل إعداد كلمة المرور لعرضها واستقبال الرسائل، لكن لا يستطيع صاحب الحساب الرد من حسابه حتى يكمل الإعداد. لا يوجد إرسال تلقائي لرسائل أو ردود باسم الحساب.

## ما يعمل

- إظهار الحساب الأصلي بصورته وشارتِه في شاشة البداية وقائمة المحادثات ورأس المحادثة ومعلومات الحساب.
- إنشاء حساب باسم مستخدم وكلمة مرور، وتسجيل الدخول والخروج وتعديل الاسم والنبذة.
- البحث عن حساب مسجّل باسمه أو باسم المستخدم، وبدء محادثة فردية.
- مجموعات تضم حتى 32 عضوًا عند الإنشاء.
- رسائل نصية مباشرة، رموز تعبيرية، مؤشرات الكتابة والاتصال، وعدّاد الرسائل غير المقروءة وعلامات القراءة.
- إرسال الصور والملفات والرسائل الصوتية. حد الملف 8 ميجابايت، وحد التسجيل دقيقتان.
- البحث داخل الرسائل المحمّلة، وتحميل التاريخ الأقدم، وتثبيت المحادثات وأرشفتها لكل مستخدم على حدة.
- حفظ الحسابات والجلسات والرسائل والمرفقات في SQLite، وإشعارات فورية عبر Server-Sent Events مع تحديث احتياطي كل 15 ثانية.
- واجهة متجاوبة للجوال والحاسوب، ولوحة مفاتيح قابلة للاستخدام، واحترام إعداد تقليل الحركة.

## التشغيل على جهازك

المطلوب: **Node.js 24** و **pnpm 10.30.3**. لا تحتاج مفاتيح Clerk أو PostgreSQL لتشغيل تطبيق المحادثات.

```bash
pnpm install --frozen-lockfile
pnpm dev
```

افتح `http://localhost:5173`. يعمل خادم المحادثات على المنفذ 5000، وتوجّه الواجهة طلباتها إليه تلقائيًا. لتغيير المنافذ: `PORT=5174 API_PORT=5001 pnpm dev`.

أنشئ حسابًا، ثم افتح التطبيق في متصفح آخر أو نافذة خاصة وأنشئ حسابًا ثانيًا. ابحث باسم الحساب الآخر من زر «محادثة جديدة»، ثم ابدأ التراسل. الحساب الأساسي المحفوظ من المشروع هو الحساب الوحيد الذي يُضاف تلقائيًا. لا تُضاف رسائل تجريبية؛ محادثة الحساب الأساسي تُفتح عند دخول الزائر.

## البناء والتشغيل من خادم واحد

```bash
pnpm build
pnpm start
```

افتح `http://localhost:5000`؛ الخادم يقدّم الواجهة المبنية وواجهة API معًا. على خادم الاستضافة اضبط `PORT` حسب المنفذ المطلوب.

| المتغير           | الاستخدام                                                                                  |
| ----------------- | ------------------------------------------------------------------------------------------ |
| `CHAT_DB_PATH`    | المسار المطلق لملف SQLite على قرص دائم؛ الافتراضي `data/wisal.sqlite` داخل مجلد خادم API   |
| `PORT`            | منفذ الواجهة أثناء التطوير، أو منفذ خادم الإنتاج؛ افتراضيًا 5173 للتطوير و5000 للإنتاج     |
| `API_PORT`        | منفذ API أثناء تشغيل `pnpm dev`؛ افتراضيًا 5000                                            |
| `APP_ORIGIN`      | أصل رابط التطبيق، مثل `https://chat.example.com`، عند الحاجة لتحديد الأصل المسموح خلف وكيل |
| `TRUST_PROXY=1`   | تفعيله فقط خلف وكيل عكسي موثوق واحد يضبط ترويسات Forwarded                                 |
| `COOKIE_SECURE=1` | طلب ملفات ارتباط عبر HTTPS فقط في الإنتاج                                                  |

انسخ `.env.example` كمرجع للمتغيرات. مرّر القيم من بيئة التشغيل أو خدمة الاستضافة؛ لا يوجد تحميل تلقائي لملف `.env`.

الاستضافة تحتاج **عملية خادم واحدة وقرصًا دائمًا** مع نسخ احتياطي لقاعدة البيانات. لا تستخدم قرصًا مؤقتًا أو عدة نسخ Autoscale لهذه النسخة. SQLite والرسائل الفورية في الذاكرة مخصصان هنا لخادم واحد؛ التوسع لعدة خوادم يحتاج قاعدة بيانات مشتركة وقناة أحداث مشتركة. لم يتم نشر التطبيق على استضافة عامة ضمن هذا التعديل.

## حدود النسخة الحالية

هذه نسخة ويب أولى، وليست تطبيق واتساب الرسمي. الحسابات تستخدم أسماء مستخدمين، بلا تحقق SMS أو استيراد لجهات اتصال الهاتف. لا تشمل المكالمات أو الحالات أو الإشعارات عند إغلاق الصفحة أو إدارة أعضاء المجموعة بعد إنشائها أو استعادة كلمة المرور.

كلمات المرور مشتقة بـ scrypt، والجلسات ملفات ارتباط HttpOnly وSameSite، والمحادثات والمرفقات محمية بعضوية المحادثة. **الرسائل ليست مشفرة من طرف إلى طرف**؛ يستطيع مشغّل الخادم الوصول إلى قاعدة البيانات، لذلك يجب استخدام HTTPS وقرص محفوظ ونسخ احتياطية محمية عند النشر. يتطلب تسجيل الصوت HTTPS أو localhost ودعم MediaRecorder وإذن الميكروفون. خط الواجهة يُحمّل من Google Fonts مع بدائل محلية عند عدم الاتصال.

## التحقق

```bash
pnpm typecheck
pnpm test
pnpm build
```

تغطي اختبارات التكامل الحسابات، وحدود الوصول، والتراسل بين حسابين، ومنع تكرار الإرسال عند إعادة المحاولة، وعلامات القراءة، والمجموعات، والمرفقات وحجمها واستمرار حفظها، والتحديث الفوري، والأرشفة الخاصة بكل حساب، وتقسيم التاريخ، وتسجيل الخروج. اختبارات الصفحة القديمة محفوظة أيضًا. ملف `artifacts/api-server/tsconfig.json` يفحص نقطة الدخول الحالية وملفات المحادثات؛ مسارات API القديمة غير مستخدمة في التطبيق الجديد.
